# perceptrum.com

Placeholder website for https://www.perceptrum.com (the apex redirects there), served by GitHub Pages from `main` (root).

- Edit `index.html` and push to `main`; Pages republishes in a minute or two.
- `CNAME` holds the custom domain (`www.perceptrum.com`, as GitHub recommends); GitHub manages it from Settings > Pages.
- DNS for the apex and `www` is at Bluehost: four `@` A records to GitHub Pages and `www` CNAME `perceptrum.github.io.`
