# perceptrum.com

Placeholder website for https://perceptrum.com, served by GitHub Pages from `main` (root).

- Edit `index.html` and push to `main`; Pages republishes in a minute or two.
- `CNAME` holds the custom domain; GitHub manages it from Settings > Pages.
- DNS for the apex and `www` is at Bluehost: four `@` A records to GitHub Pages and `www` CNAME `perceptrum.github.io.`
